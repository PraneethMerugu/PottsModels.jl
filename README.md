# PottsModels.jl

Reusable scientific model declarations and executable modeling tutorials for
Potts.jl. Factories construct fresh systems and initial conditions; callers own
the problem, algorithm, seed, precision, backend and saving policy.

Initial models are bounded CPU examples of activity-coupled migration,
field-coupled vasculogenesis and monolayer division. They are not calibrated
paper reproductions and do not establish GPU or arbitrary-combination support.

See [the tutorials](docs/src/index.md) and [contributor workflow](CONTRIBUTING.md).
